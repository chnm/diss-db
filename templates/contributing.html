Contributing to the Database

The History Dissertation Database is community-editable. Authenticated users can add new scholars and dissertations, update existing records, and manage committee information. This guide walks you through how to contribute.

Adding a Scholar

  1. Go to the Scholars page.
  2. Click the "+ Add Scholar" button.
  3. Fill in the name fields (first, middle, last, suffix) and any additional information such as affiliation or ORCID.
  4. Click Save to create the scholar record.

Adding a Dissertation

  1. Navigate to the scholar's profile page (search for them on the Scholars page and click their name).
  2. Click "Add Dissertation" on the scholar's profile.
  3. Fill in the dissertation title, completion year, school, and department.
  4. Click Save to create the dissertation.
  5. After saving, you can edit the dissertation to add links and committee members (see below).

Editing a Scholar or Dissertation

  1. Navigate to the scholar's profile or dissertation page.
  2. Click the Edit button.
  3. Modify the fields you want to update.
  4. Click Save to apply your changes.

Managing Committee Members

Committee members link scholars to dissertations. The chair role represents the dissertation advisor and is used to build the scholarly genealogy tree.

  1. Go to the dissertation's edit page.
  2. In the Committee Members section, use the autocomplete search to find an existing scholar.
  3. Select the role: Chair (advisor) or Reader (committee member).
  4. If the scholar doesn't exist yet, you can create a new scholar record using the modal that appears.
  5. Click Save to save the committee assignments.

Managing Links

You can attach links to a dissertation record for ProQuest, institutional repositories, or PDF copies.

  1. Go to the dissertation's edit page.
  2. In the Links section, add the URL and select the link type.
  3. Click Save to store the links.

Tips

  • Search before adding: Use the Scholars page to check if a person already exists before creating a new record.
  • Fuzzy search: The search is fuzzy, so minor typos or variations in spelling will still return results.
  • Login required: You must be logged in to add or edit records. If you don't have an account, request access.

Questions?

If you have questions about contributing or encounter any issues, please contact the RRCHNM team.

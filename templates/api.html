{# ── Header ── #}
Developer API · v1

Query the catalogue directly.

A read-only, public HTTP API over the dissertation and scholar records. Every response is JSON, every list is paginated, and no key is required. Use it to build tools, run analyses, or trace scholarly genealogies programmatically.

{# ── At a glance ── #}
Base URL
/api/v1/
Format
JSON
Auth
None (read-only)
Rate limit
120 req / min
{# ── Endpoints overview ── #}

Endpoints

Method Path Description
GET /dissertations/ Paginated, filterable dissertation list
GET /dissertations/{id}/ A single dissertation with committee, abstract, emphases, links
GET /scholars/ Paginated, filterable scholar list
GET /scholars/{id}/ A single scholar with authored & advised dissertations

Dissertations

Query parameters · /dissertations/
{% include "api/_param.html" with name="q" desc="Fuzzy title search (trigram + substring)." %} {% include "api/_param.html" with name="year" desc="Exact publication year, e.g. 2018." %} {% include "api/_param.html" with name="year_min / year_max" desc="Inclusive year range bounds." %} {% include "api/_param.html" with name="school" desc="School id — all dissertations from an institution." %} {% include "api/_param.html" with name="author" desc="Scholar id of the dissertation's author." %} {% include "api/_param.html" with name="advisor" desc="Scholar id of the committee chair (advisor)." %} {% include "api/_param.html" with name="thematic_emphasis / geographic_emphasis" desc="Emphasis id to filter by field." %} {% include "api/_param.html" with name="ordering" desc="year, -year, title, id (prefix - to reverse)." %} {% include "api/_param.html" with name="page / page_size" desc="Page number and size (default 25, max 100)." %}
Example request
curl "{{ request.scheme }}://{{ request.get_host }}/api/v1/dissertations/?year_min=2015&geographic_emphasis=1&ordering=-year"
Example response · list item
{
  "count": 58683,
  "next": ".../api/v1/dissertations/?page=2",
  "previous": null,
  "results": [
    {
      "id": 57669,
      "title": "A Test of Conscience…",
      "year": 2022,
      "author":  { "id": 29319, "name_full": "Steven Server",  "api_url": ".../scholars/29319/" },
      "school":  { "id": 165,   "name": "University of Chicago" },
      "advisor": { "id": 1668,  "name_full": "Emilio Kouri",   "api_url": ".../scholars/1668/" },
      "site_url": ".../dissertations/57669/",
      "api_url":  ".../api/v1/dissertations/57669/"
    }
  ]
}

The /dissertations/{id}/ detail response adds abstract, department, the full committee (chair first, then readers), thematic_emphases, geographic_emphases, and links.
